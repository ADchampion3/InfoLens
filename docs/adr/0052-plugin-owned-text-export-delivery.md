# Plugin-Owned Text Export Delivery

Plugins own user-facing export behavior, including available formats, presets, presentation, generated content, and whether a format may be copied or downloaded. The Host Shell does not discover or invoke exports, and the Plugin SDK defines no export UI or export SPI. A future Workbench will consume a separate Plugin Context SPI for LLM and tool use; it will not parse or depend on export artifacts.

This decision replaces ADR 0051's JSON-only response. `downloadableResponse` accepts only `{ filenameBase, format, body }`, with no compatibility overload. `format` is one of `json`, `csv`, `markdown`, or `text`; Plugin Runtime derives the corresponding `.json`, `.csv`, `.md`, or `.txt` extension and MIME type. `filenameBase` may contain safe Unicode, while Runtime rejects control characters, path syntax, reserved names, and excessive length and emits a safe ASCII fallback plus an RFC 5987 UTF-8 filename. `body` is an iterable or async iterable of strings encoded by Runtime as UTF-8. Runtime validates transport shape but does not validate JSON, CSV, Markdown, source fields, or business-data redaction; those remain Plugin responsibilities.

The Plugin SDK exposes transport helpers rather than presentation. `downloadExport(route)` resolves only below the calling Plugin's own `apiBaseUrl`, starts a direct browser download, and reports only that the download was initiated. Downloads remain streaming, use backpressure, and have no fixed size limit. A request-scoped `AbortSignal` is added to Plugin Route handlers so client disconnects stop response iteration and Plugin-owned work.

`copyDownloadable(route)` reads the same Plugin API response used for download and writes it with the browser Clipboard API, so copy and download share one Plugin serializer. It accepts only the four text MIME types, stops once the UTF-8 payload exceeds 1 MiB, requires an explicit user gesture, and reports `EXPORT_REQUEST_FAILED`, `EXPORT_TOO_LARGE`, `UNSUPPORTED_EXPORT_TYPE`, `CLIPBOARD_UNAVAILABLE`, or `CLIPBOARD_DENIED`; Plugins own the user-facing messages. The Workspace Frame grants trusted Plugin Workspaces `clipboard-write` but not clipboard read access; helpers reject cross-origin and cross-plugin routes. The SDK provides no fallback Electron IPC and no automatic copy behavior.

All Bundled Plugins migrate to the new response contract in one breaking change. Each remains free to expose any subset of the four formats and to design its own export controls, defaults, presets, serialization, and error messages.
