# Domain Docs

This repository uses a single-context domain documentation layout.

## Before Exploring

- Read the root `CONTEXT.md` for the project glossary.
- Read relevant decisions under `docs/adr/` before changing an architectural area.
- If either location is absent, proceed without requiring it to be created.

## Vocabulary

Use terms exactly as defined in `CONTEXT.md`, including Plugin Runtime, Host Shell, Host State, Application Session, and Plugin Diagnostic Report. Avoid synonyms that the glossary explicitly rejects.

## Architectural Decisions

Surface conflicts with existing ADRs explicitly. Do not silently replace an established decision; add or supersede an ADR when a new accepted specification changes that decision.
